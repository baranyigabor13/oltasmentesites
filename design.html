Design System Specification

Project Context: A digital knowledge base for parents navigating legal and administrative procedures related to mandatory vaccinations.
Vibe: Organized, objective, trust-building, calm. Not an activist site, not a dry legal portal.

1. Visual Direction

  • Tone: Calm, objective, and reassuring.
  • Style: Clean lines, soft rounded corners (friendly but professional), plenty of white space.
  • Avoid: Danger reds (which induce panic), excessive drop shadows (startup vibe), or dense unbroken text blocks (official legal portal vibe).

3. Typography System

  • Headings: Merriweather (Serif). Used for titles to convey established knowledge, trust, and a slight documentary feel.
  • Body Text: Inter (Sans-serif). Highly legible for long reading sessions and mobile screens.
  • Hierarchy: H1 (36px), H2 (24px), H3 (20px), Body (16px), Small (14px).

4. Spacing and Layout System

  • Grid: 8px baseline grid system.
  • Container: Max-width of 800px for optimal reading measure (approx. 65-75 characters per line).
  • Padding: Generous whitespace. Components use 16px (md), 24px (lg), or 32px (xl) padding.

5. Card Design Rules

  • Cards must have a pure white background (#FFFFFF) against the slightly gray body background (#F8FAFC).
  • Use a subtle 1px border (#E2E8F0) and a very soft, minimal shadow.
  • Border-radius should be 12px to appear approachable.

6. Category, Institution, and Severity Badges

  • Shape: Pill-shaped (fully rounded).
  • Institution (e.g., Védőnő, Gyámhivatal): Soft blue background with darker blue text.
  • Category (e.g., Tájékoztatás): Soft teal background with dark teal text.
  • Severity/Deadlines: Soft amber background with amber border and dark amber text (Avoid red).

7. Warning Box Styles

Warnings must not induce panic. Instead of a bright red box with an exclamation mark, use a soft amber box with a colored left border to gently draw attention to important legal or deadline information.

Fontos: A hivatalos iratokat minden esetben ajánlott átvenni, az átvétel megtagadása hátrányos jogkövetkezményekkel járhat.

8. Event Card Layout (Listing)

A layout representing a timeline event in the procedure.

  • Top Row: Date / Timestamp (muted text) + Institution Badge aligned right.
  • Middle: Bold clear title (e.g., "Határozat kézbesítése").
  • Bottom: Brief summary (2 lines max) + "Next step" indicator or link.

9. Event Detailed Page Layout

A clean, article-like layout for explaining an event deeply.

  • Header: Breadcrumbs (Vissza az áttekintéshez) -> Title (H1) -> Meta data (Institution, Legal deadline badge).
  • Content Area: Narrow reading width (max 700px). Use bullet points for readability.
  • Action Section: A highlighted box at the bottom: "Mit tehet a szülő?" (What can the parent do?) containing clear, actionable, objective steps.

10. Homepage Section Suggestions

  1. Hero Section: Calm, reassuring headline. E.g., "Tájékozódjon jogairól és a közigazgatási folyamatokról." No aggressive call-to-actions.
  2. Process Overview (Timeline): A visual, step-by-step horizontal or vertical timeline showing the typical path (Védőnő -> ... -> Bíróság).
  3. Institution Directory: Grid of cards detailing what each actor (Gyámhivatal, NAV) does in this context.
  4. Knowledge Base / FAQ: Accordion style questions for quick answers to common parental fears.

11. Micro-interactions

  • Hover States: Cards should gently lift up by 2px on hover.
  • Buttons: Background color smoothly darkens over 0.2s. No bouncing or aggressive scaling.
  • Accordions: Content slides down smoothly (easing).

12. Accessibility (a11y) Rules

  • Contrast: All text must meet WCAG 2.1 AA standards (e.g., dark slate on light backgrounds).
  • Focus States: Interactive elements (links, buttons) must have a clearly visible outline when navigated via keyboard.
  • Readable Sizing: Base font size should be at least 16px. Avoid setting text in light gray that is hard to read.
  • Screen Readers: Use semantic HTML (<nav>, <main>, <article>) and aria-label for icon-only buttons.

/* Variables */

  --color-primary-main: #3B82F6;

  --color-warning-text: #B45309;
  --shadow-sm: 0 1px 2px rgba(0,0,0,0.04);
