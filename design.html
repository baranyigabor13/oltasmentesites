Parental Design System

A calm, clinical, and authoritative design framework tailored for legal-administrative communication and decision mapping.

1. Visual Direction & Vibe

When parents are facing administrative processes regarding mandatory vaccinations, they enter a state of high stress. The design system must counteract this anxiety using concrete, reassuring physical-object aesthetics — resembling a judicial archive or clinical protocol register.

  • Voice and Tone: Reassuring, clinical, transparent, and authoritative.
  • Editorial Grid: A single focused layout column capped at 72ch to ensure comfortable typography line lengths (65–75 characters) and reduce cognitive overload.
  • Refusal of Alarmism: Strictly avoid raw primary warning colors (danger reds) or screaming high-contrast callouts. Important markers are framed as gold-tinted judicial folders rather than hazard signs.

2. Color Palette (OKLCH System)

A committed visual palette based on modern, accessible OKLCH values with solid HEX fallbacks. All primary typography and components meet or exceed WCAG AA contrast ratios (4.5:1 for body copy).

3. Typography Specimen

Typography is paired along a contrast axis to reflect judicial seriousness and clear digital legibility. We pair Libre Baskerville (Serif) with Work Sans (Humanist Sans-Serif).

6. Implementation Code Templates

Integrate these CSS rules directly into the root stylesheet to establish the visual core of the protocol.

:root {
  /* Color Palette - OKLCH */
  --color-bg-primary: oklch(0.98 0.005 85);       /* #FBFBF9 */
  --color-bg-secondary: oklch(1 0 0);             /* #FFFFFF */
  --color-text-primary: oklch(0.24 0.015 240);    /* #1A2433 */
  --color-text-secondary: oklch(0.42 0.02 240);   /* #42526B */
  
  --color-primary-main: oklch(0.48 0.12 250);     /* #2D5FB7 */
  --color-accent-teal: oklch(0.38 0.06 185);      /* #1C5350 */
  
  --color-warning-bg: oklch(0.98 0.01 80);        /* #FFFDF5 */
  --color-warning-border: oklch(0.88 0.06 80);    /* #EBD6A2 */
  --color-warning-text: oklch(0.42 0.08 70);      /* #6D5114 */
  
  --color-neutral-border: oklch(0.92 0.008 240);  /* #E2E7EE */

  /* Typography */
  --font-family-base: 'Work Sans', sans-serif;
  --font-family-heading: 'Libre Baskerville', serif;

  /* Dimensions */

  --radius-md: 8px;
  --radius-lg: 14px;
}
